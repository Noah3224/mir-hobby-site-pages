# Мир хобби

Учебный адаптивный сайт-каталог идей для досуга. Помогает выбрать занятие по направлению и найти его по названию или описанию.

## Возможности

- адаптивная вёрстка для телефона и компьютера;
- каталог карточек хобби;
- фильтрация по направлениям;
- поиск по карточкам;
- случайный выбор идеи;
- избранные занятия с сохранением в браузере;
- адаптивное мобильное меню;
- переходы по разделам страницы.

## Запуск

Откройте `index.html` в современном браузере. Серверная часть и установка зависимостей не требуются.

## Файлы

- `index.html` — структура страницы;
- `styles.css` — оформление и адаптивная вёрстка;
- `app.js` — каталог, поиск, фильтры, случайный выбор и избранное.
